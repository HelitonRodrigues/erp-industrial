Como montar um ERP novo a partir do backup
  1. Crie um projeto novo no Supabase.
  2. Abra o SQL Editor do projeto novo e rode o arquivo estrutura.sql que vem dentro do .zip.
  3. Em Authentication → Users, crie o seu login (você mesmo digita a senha) e rode o último comando do estrutura.sql com o seu e-mail.
  4. Publique o ERP apontando para o projeto novo (endereço e chave pública em js/supabase.js) e publique as funções criar-usuario e push-linhas.
  5. Entre no ERP novo → Backup → Importar → escolha o .zip.
  6. Saia e entre de novo. Em Usuários, toque no 🔑 de cada pessoa para criar a senha dela.
